# 反映待ち

開発用のチャットが、たろちんさんのパソコンのフォルダに書き込んだけれど、
まだ Commit と Push をしていない直しの一覧です。
次に反映する窓（たいてい翌朝のコラム）が、これを読んで一緒に反映します。
やり方は `data/パソコンから反映する手順.md` の「開発用のチャットの直しは、次の反映にまとめて乗せる」。

一緒に反映したら、下を「（いまは無し）」に書き換えて、同じ Commit に入れてください。

★**GitHub にあるこのファイルは、反映するまで古いまま。** 開発用のチャットはパソコンのフォルダにだけ書くので、
クラウドだけで動いている窓（パソコンにつながっていない日の朝の窓など）が GitHub のこれを読んで
「（いまは無し）」でも、**パソコンのフォルダには置いてある直しがあるかもしれない。**
そういう日は「無い」と言い切らず、「パソコンにつながっていないので、フォルダの反映待ちは確かめられません」と書く
（2026-11-21。朝の窓が「無し」と言ったが、実際は12ファイル置いてあった）
