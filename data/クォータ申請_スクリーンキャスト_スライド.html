Hayarige
YouTube Data API v3 — compliance review

https://hayarige.com/

A personal website, operated by one individual in Japan. It publishes a daily ranking of which video games Japanese-speaking streamers are playing on YouTube.

We use an API key only. We do not use OAuth, and we hold no user data.

This screencast shows, in order: 1. how we retrieve recent uploads  2. how we identify the game  3. how we build the daily ranking  4. the published result.
Scene 2 / 9 — step 1a

The channel list

We maintain a list of about 4,100 Japanese-language YouTube channels that regularly stream games. The list is public in our repository.

Because of the current 10,000 unit daily limit we cannot call the API for all of them in one run. Each run covers the 2,000 largest channels plus one seventh of the remainder on a weekly rotation — about 2,050 channels per run.

Lifting that rotation is the main reason for this quota request.

Scene 3 / 9 — step 1b

The only two endpoints used for the daily ranking

playlistItems.list part=contentDetails, maxResults=10 one call per channel = 1 unit returns the video IDs of that channel's newest uploads videos.list part=snippet,statistics,contentDetails, liveStreamingDetails,player up to 50 IDs per call = 1 unit returns title, publish time, duration, view count

We also call channels.list when refreshing channel metadata, and search.list only when discovering new channels to add to the list. search.list is never used to build the daily ranking.

We never download, cache or store audiovisual content, and we do not embed or modify the YouTube player.

Scene 5 / 9 — step 1d

What we store

For each video we store only these fields, exactly as the API returns them:

id, title, publishedAt, channelId, channel title, viewCount, duration, thumbnail URL, live / not live quota_used: 2467 ← we record our own API usage every run

View counts are stored and displayed exactly as videos.list returns them. We do not recompute, estimate or adjust any metric that the API returns.

Everything in this file — titles, channel names, thumbnail URLs — is deleted after 30 calendar days. Scene 8 shows that.

Scene 6 / 9 — step 2

Identifying the game from the stream title

The API does not tell us which game a live stream is about, so we identify it ourselves from the stream title. Our dictionary has two parts: game names imported from the IGDB game database, and 289 rows of aliases we write and maintain by hand, because Japanese streamers use abbreviations and spellings no database has.

All three of these titles are identified as Dragon's Dogma II: Dark Arisen:

【ドラゴンズドグマ2：ダークアリズン】待ちに待ったダークアリズン！本日発売 #1 神ゲーの予感がするドラゴンズドグマ 2：ダークアリズン 【 ドラゴンズドグマ２ ダークアリズン / Dragon's Dogma 2: Dark Arisen 】

This game tag is our own label. It is additive to YouTube's own video categories and does not replace or modify them. We state this on every page of the site.

Scene 7 / 9 — step 2b

Titles we cannot identify are reviewed by a person

Unidentified titles are listed on an internal review page. They are not guessed.

The site owner reads this list every morning and adds a dictionary entry only after confirming the game against a primary source — the publisher's own announcement, the Steam store page, or a games news outlet.

If we cannot confirm what game a title refers to, we leave it uncounted.

Scene 8 / 9 — step 3

Generating the daily ranking

For each game we count, within the last 24 hours of collected data:

  • videos — how many streams mentioned that game. Multiple uploads from the same channel are discounted, so one channel posting ten parts does not outweigh ten channels
  • channels — how many distinct channels streamed it
  • views — the sum of view counts returned by videos.list
score = videos x 0.30 + channels x 0.35 + views x 0.35 (each normalised to the day's maximum; views on a log scale)

The ranking is a ranking of games. We do not score, rank or rate individual channels or creators, and we publish no per-creator metric of any kind.

Closing

Summary

What we do

  • call playlistItems.list and videos.list twice a day for about 2,050 Japanese-language gaming channels
  • identify the game from the stream title using our own hand-maintained dictionary, with unidentified titles reviewed by a person
  • publish a daily ranking of games, with our own counts clearly labelled as ours
  • delete all API-derived text after 30 days

What we do not do

  • no OAuth, no user data, no cookies
  • no scoring or rating of individual channels or creators
  • no estimates of revenue, watch time, reach, demographics, monetization or brand suitability
  • no modification of any metric returned by the API
  • no scraping, no storage of audiovisual content, no embedded player
Closing

Why we need more quota

  • The 10,000 unit default forces a weekly rotation, so most of our 4,100 channels are checked once a week instead of every run. A game streamed only by channels we did not check that day is invisible to us.
  • On 2026-09-26 we exhausted the default quota and lost that day's collection entirely.
