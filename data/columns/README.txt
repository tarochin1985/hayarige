コラム（今日の注目ゲーム）の入れ方
====================================

■ 置き場所

  data/columns/YYYY-MM-DD.json

  この日付の日に、サイトの一番上に表示されます。
  ファイルが無い日はコラム欄ごと消えます（それが正常な状態です）。


■ 手順（GitHubの画面だけで完結します）

  1. Code タブ → data フォルダ → columns フォルダ を開く
  2. その画面で「Add file」→「Upload files」
  3. もらった JSON ファイルをドラッグ＆ドロップ
  4. 下の緑の「Commit changes」

  ※ フォルダごと渡された場合は、1〜2 を飛ばして
     Code タブ直下で data フォルダをまるごとドラッグしてもOK。
     既存のファイルは消えず、追加されるだけです。

  反映は次の更新から。すぐ見たいときは
  Actions →「3. 毎日の更新」→「Run workflow」。


■ 書式

  {
   "game": "Minecraft",
   "headline": "見出し。出来事を一文で言い切る",
   "body": "本文120〜480字。裏が取れた事実だけ。",
   "people": ["配信者名", "..."],
   "sources": [{"t": "出典の見出し", "u": "https://..."}],
   "buy": {"t": "Amazonで買う", "u": "https://www.amazon.co.jp/dp/..."}
  }

  game / headline / body は必須。people / sources / buy は任意。
  game はランキングの表記と揃えると、Steamへのリンクが自動で付きます。


■ チェックに引っかかると載りません

  scripts/check_column.py が下を機械的に見ています。

    ・出典が0件
    ・まとめサイトが出典に入っている
    ・「〜とみられる」「話題を呼んで」など推測の言い回し
    ・本文が120字未満、または480字超
    ・buy に検索結果のURL（商品ページ以外）

  引っかかった日は、その日はコラム無しになります。
  Actions の実行ログに理由が出ます。


■ 書き方のルール

  data/columns/EDITORIAL.md に全部書いてあります。
  いちばん大事なのは「書くことが無い日は書かない」です。
