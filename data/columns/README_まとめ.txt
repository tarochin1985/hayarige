週・月のまとめの置き方
======================

毎日のコラムが「その日起きたこと」なのに対して、こちらは
1日を見ているだけでは分からないことを書く読みものです。
2026-09-14に、Xに流して消えるのはもったいないという話になり、
サイトにも残すことにしました。

置き場所
--------
  data/columns/weekly/YYYY-MM-DD.json    その週の月曜の日付
  data/columns/monthly/YYYY-MM.json      その月

  → 出てくるページ
  /w/YYYY-MM-DD/   /m/YYYY-MM/   一覧は /matome/

形（週と月で同じ。週は sections が1つ、月は3〜5つ）
--------------------------------------------------
{
 "title": "30歳の誕生日に、界隈が拠点を焼き合った4日間",
 "lead": "リード。1〜2文。無くてもよい",
 "sections": [
  {"h": "小見出し（月まとめのときだけ。週は省いてよい）",
   "body": "本文。改行で段落が分かれます。"}
 ],
 "sources": [
  {"t": "出典の見出し", "u": "https://..."}
 ]
}

書き方は data/columns/EDITORIAL.md と同じです。特に:
 - title は10〜30字のキャッチコピー。説明の一文にしない
 - 順位を本文の主役にしない
 - 「当サイトの集計では」と主語を付ける
 - 「初めて」と書く前に site/d/ の全日付を数える
 - 出典は一次ソースのみ。まとめサイトは使わない

形が違うもの・出典が無いものは、サイトに出ません（更新のログに理由が出ます）。
