## ステップ4／スライド4枚目「A real collection run」★いちばん大事

**タブ2で開く（このURLをそのまま貼ってください）:**

```
https://github.com/tarochin1985/hayarige/actions/workflows/3-daily.yml?query=event%3Aschedule
```

> **末尾の `?query=event%3Aschedule` を省かないでください。**
> これは**「自動で動いた回」だけに絞る**ための指定です。理由は下の⚠️。

**すること:**

1. 実行の一覧が出ます。**いちばん上の、緑のチェックが付いた行の題名をクリック**
2. 開いた画面の**左側に `Jobs` という見出しがあり、その下に `update` という
   行が1つだけ**あります。**`update` をクリック**
   （左側に何も無ければ、画面の真ん中あたりにある `update` の行でも同じです。
   **押すのは `update` です**）
3. 工程の名前が縦に並びます。日本語で
   `新作を辞書に足す` `新着の配信を集める` `集計してサイトを作る` …
   **`新着の配信を集める` の行をクリックして開く**
4. ログが開きます。**ゆっくりスクロール**して、こういう行を映す（20秒）

```
対象: 毎日 2000 件 + 今日の当番 56 件（登録済み 4120 件）
  100/2056 件 ／ 使用クォータ 100
  ...
詳細を取る候補 3,xxx 本 ／ 使用クォータ 2,4xx
保存しました: data/daily/2026-10-11.json （2,4xx 本 ／ …）
```

5. **「使用クォータ」の数字をマウスで指す**

> **ここが申請理由そのものです。**「毎日2000件＋今日の当番56件（登録済み4120件）」
> ＝ 上限があるせいで4,120件を毎回は見られていない、が画面に出ます。

### ⚠️ 手で回した回を選ぶと、ログが空になります

`3. 毎日の更新` は、**手で回すときに「配信を取り直す: no」を選べます。**
辞書を直した日はいつもこちらを使っているので、**最近の実行のほとんどが
`no` の回**です。`no` の回は `新着の配信を集める` が**飛ばされて**、
代わりに `収集を飛ばしました` という行が出るだけになります。

だから上のURLで **`event:schedule`（自動で動いた回）に絞って**います。
自動の回は毎日7時と19時に動いていて、**必ずAPIを叩いています。**

絞り込みが効いているかの見分け方:

- 一覧の各行に **`Scheduled`** と出ていれば正解
- **`tarochin1985` が手で回した** と出ている行は使わない

### ⚠️ ほかの工程は開かないでください

`新着の配信を集める` だけ開きます。ほかを開くと時間が延びるだけです。

→ タブ1に戻る → 右矢印

主な内容:

- 11 … 30日でAPI由来の文字を全部消していること
