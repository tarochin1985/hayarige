```
Step 2 - identifying the game from the stream title

The YouTube API does not tell us which game a live stream is about, so we
identify it ourselves from the stream title.

Our dictionary has two parts:
  - game names imported from the IGDB game database
  - 289 rows of aliases that we write and maintain by hand, because Japanese
    streamers use abbreviations and Japanese spellings that no database has

Example - all of these titles are identified as
"Dragon's Dogma II: Dark Arisen":

  【ドラゴンズドグマ2：ダークアリズン】待ちに待ったダークアリズン！本日発売
  #1 神ゲーの予感がするドラゴンズドグマ 2：ダークアリズン
  【 ドラゴンズドグマ２ ダークアリズン / Dragon's Dogma 2: Dark Arisen 】

This game tag is OUR OWN LABEL. It is additive to YouTube's own video
categories and does not replace or modify them. We state this on every page
of the site.
```

**(b) 人が確認している画面**
→ https://hayarige.com/admin/

やること: 開いて「確認待ち」「見落とし候補」の一覧を見せる。

```
Step 2b - human review

Titles we could not identify are listed here for manual review, not guessed.
A person (the site owner) reads this list every morning and adds dictionary
entries only after confirming the game against a primary source - the
publisher's own announcement, the Steam store page, or a games news outlet.

If we cannot confirm what game a title refers to, we leave it uncounted.
```

## 場面7 ── ランキングの作り方（50秒）★3つ目の質問の答え

映すもの: GitHubの `scripts/build_site.py` の32行目
→ https://github.com/tarochin1985/hayarige/blob/main/scripts/build_site.py#L32

画面に出す英文:

```
Step 3 - generating the daily ranking

For each game we count, within the last 24 hours of collected data:

  videos    how many streams mentioned that game
            (multiple uploads from the same channel are discounted, so that
             one channel posting ten parts does not outweigh ten channels)
  channels  how many DISTINCT channels streamed it
  views     the sum of view counts returned by videos.list

  score = videos x 0.30 + channels x 0.35 + views x 0.35
          (each normalised to the day's maximum; views on a log scale)

The ranking is a ranking OF GAMES. We do not score, rank or rate individual
channels or creators, and we publish no per-creator metric of any kind.

We do not estimate revenue, watch time, reach, audience demographics,
monetization status or brand suitability.
```

## 場面9 ── 終わりの表紙（30秒）

```
Summary

What we do
  - call playlistItems.list and videos.list twice a day for about 2,050
    Japanese-language gaming channels
  - identify the game from the stream title using our own hand-maintained
    dictionary, with unidentified titles reviewed by a person
  - publish a daily ranking of GAMES, with our own counts clearly labelled
    as ours
  - delete all API-derived text after 30 days

What we do not do
  - no OAuth, no user data, no cookies
  - no scoring or rating of individual channels or creators
  - no estimates of revenue, watch time, reach, demographics, monetization
    or brand suitability
  - no modification of any metric returned by the API
  - no scraping, no storage of audiovisual content, no embedded player

Why we need more quota
  - the 10,000 unit default forces a weekly rotation, so most of our 4,100
    channels are checked once a week instead of every run
  - on 2026-09-26 we exhausted the default quota and lost that day's
    collection entirely

Requested: 40,000 units/day (excluding search.list) + 10,000 for search.list

Thank you for the review.
```
